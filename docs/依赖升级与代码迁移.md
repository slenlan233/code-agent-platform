# 依赖升级与代码迁移

日期：2026-10-25。

本文记录前一轮的依赖升级及 API 迁移。后续已实现基础权限、审批、Docker 验证、本地图谱和 Web 控制台；具体范围与边界见 [平台升级实现与验收](平台升级实现与验收.md)，不能将其视作完整企业生产平台。

0.4.0 新增 `langchain-deepseek==1.1.1`，保留既有 LangChain/LangGraph 版本组合，并补齐思考模式的工具选择和字段回传适配。真实模型和 PowerShell 联调结果见 [PowerShell 与 DeepSeek 接入](PowerShell与DeepSeek接入.md)。

FastAPI 原先是未写入项目配置的本地额外包，其 0.115.6 与旧锁文件中就已有的 Starlette 1.6.0 不兼容。本次通过可选 api 依赖升级 FastAPI，避免为兼容旧 FastAPI 而降级整个项目的 Starlette。

## 2. 代码迁移

### Agent API

- 原 create_react_agent、initialize_agent 改为 langchain.agents.create_agent。
- 原 prompt 参数改为 system_prompt；现有模板先格式化为字符串。
- 调用输入统一使用 messages；普通答案从 messages 最后一条读取。
- 计算示例使用 ToolStrategy 和 structured_response 返回经过校验的结果。
- 主助手按消息的 text 属性读取文本，兼容字符串和文本内容块。
- 流式事件中不再假定模型节点名为 agent；回归覆盖 model 与 tools 节点。

### 多 Agent 示例

上游已经建议从不再维护的 langgraph-supervisor 转向主 Agent 加工具封装子 Agent。

新增 app/code_agent/agent/team.py，为每个子 Agent 同时提供同步和异步工具包装，传递运行配置，并将子 Agent 最终答案返回主 Agent。两处多 Agent 示例都改用这一方式。该改动用于替代原有协作 API，完整的平台角色权限和结构化证据交接仍需后续实现。

### Checkpoint

原 FileSaver 的 pending writes 方法为空，并依赖自定义 pickle/JSON 格式。本次改用官方 SqliteSaver 和 AsyncSqliteSaver：同步示例使用 FileSaver 上下文管理器；异步主助手在整个会话中持有 get_file_saver 上下文。

新数据库为 .temp/checkpoint/checkpoints-v2.sqlite，旧 JSON 文件未删除，也未自动反序列化导入。新旧会话格式不自动互通。

### 模型与 MCP

- 限时多 Agent 示例通过新的 create_model 工厂创建独立客户端，移除手动修改底层客户端的写法。
- MCP 数学示例使用当前 Python 解释器和相对模块位置定位服务脚本。
- 已迁移的联网示例增加 main 入口保护，导入模块时不会直接执行示例请求。
- 保留可见终端所需的长会话上下文；无需持久状态的工具继续使用现有 MCP 客户端发现机制。

## 3. 安装与验证

```powershell
uv sync --locked --inexact
# 当前本地环境还安装了修复后的可选 FastAPI：
uv sync --locked --inexact --extra api

uv run --no-sync python -m unittest discover -s tests -v
uv pip check --python .venv/Scripts/python.exe
```

首次同步时安装工具清理了项目配置之外的开发包，随后已按原版本恢复；后续使用 --inexact 保留这些额外包。

新增兼容性回归覆盖：

1. 主 Agent 的真实工具分发、流式节点和文本内容块。
2. 结构化计算结果，以及计算工具不会提前结束任务。
3. 同步和异步子 Agent 调用。
4. 独立模型客户端的超时和重试配置。
5. 同步 SQLite checkpoint 重启后的历史恢复与会话隔离。
6. 异步 SQLite checkpoint 的暂停、重启、恢复和完成状态保持。
7. 真实本地 MCP stdio 服务的工具发现与调用。
8. 原有 Shell、终端和工具状态回归。

以上测试不调用付费模型、云知识库、真实数据库或浏览器；MongoDB、Redis、Lima 以及具体模型供应商的联网端到端行为尚未验证。

本次验证结果：30 项测试全部通过；app、src、tests 的 Python 语法编译通过；uv lock --check 通过；已安装的 168 个包通过 uv pip check，无依赖冲突。测试输出保存在 .temp/dependency-upgrade-tests.txt。

升级前的锁文件备份在 .temp/dependency-upgrade-backup/uv-before-upgrade.lock，仅供对照和回退参考。若回退库版本，代码与锁文件需要一起回退。
