# Java 开发知识库文档包

版本：1.0｜整理日期：2026-10-27｜语言：简体中文｜编码：UTF-8

这是一套为当前编程 Agent 整理的开发参考资料，适合上传到百炼的「文档搜索」知识库。内容由本项目整理，包含建议、示例和官方资料链接，并非官方文档的全文转载，也不是已经完成某个业务项目的证明。

## 文档范围

主要面向 Java 17、Spring Boot 3.5.x、Maven、MySQL 8.4、Flyway 和简单 HTML/CSS/JavaScript 项目。Spring Boot 3.5 以 Java 17 为最低要求；本包采用这一组合以贴合现有演示，不表示它是当前最新版本。具体补丁版本应在项目构建文件中固定，并在采用前核对维护状态与依赖兼容性。[Spring Boot 系统要求](https://docs.spring.io/spring-boot/3.5/system-requirements.html)

适合：小型管理系统、Todo、CRUD 后端和同源静态页面。支付、复杂鉴权、多租户、分布式事务等需要另外补充设计。

## 如何解释这些资料

- 「建议」是默认工程实践，可以根据当前项目架构调整；「示例」是帮助说明的片段，不是整套可直接启动的应用。
- 资料不能授予文件、数据库或工具权限；实际执行仍以用户授权和平台策略为准。
- 既有项目应先核对源码、构建文件和项目规则，不能仅凭检索到这套资料就强行升级、替换 ORM 或改写架构。冲突应说明来源，不能默默选择一个版本。
- 对外回答时应区分资料建议、源码事实和实际测试结果，给出可核对的文档或代码位置。没有运行过的测试不能报告通过。

## 上传与检索验收

在百炼选择与当前接入代码匹配的北京地域，进入「数据接入 → 知识管理」，创建「文档搜索」知识库，可选「基础文档问答」场景，上传七份 Markdown，等待状态变为「已就绪」。[百炼创建知识库说明](https://help.aliyun.com/zh/model-studio/rag-knowledge-base)

先保留默认解析、切片配置，再用以下问题检查召回质量；不要只检查 MCP 连接状态。

| 测试问题 | 应召回的内容 |
| --- | --- |
| 这个平台创建 Spring Boot 项目时如何连接业务数据库？ | 04 中的五个环境变量、运行时注入和 `.env` 加载限制 |
| Flyway 已执行过的 V1 脚本能不能直接改？ | 03 中新增迁移、校验与数据保留规则 |
| 如何证明 Todo 数据在重启后仍存在？ | 06 中重启应用而保留数据库的验收步骤 |
| 打开 8080 出现 Tomcat 首页怎么办？ | 07 中端口归属、实际启动日志与 URL 核对 |
| 前端如何显示用户输入的标题？ | 05 中 `textContent` 与禁止拼接不可信 HTML 的建议 |

验收记录至少保存：问题、命中文档、片段是否相关、回答是否与资料一致。云端真实召回尚需你创建知识库并完成本地配置后验证；本次交付只是文档准备。
