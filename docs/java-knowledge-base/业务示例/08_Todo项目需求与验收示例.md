# Todo 项目需求与验收示例

文档编号：JAVA-KB-DEMO-08｜版本：1.0｜日期：2026-10-27
适用范围：从空目录创建的本地单用户 Todo 演示。性质：可选业务示例，不是所有 Java 项目的通用要求。

## 1. 产品范围

使用 Java 17、Spring Boot 3.5.x、Maven、MySQL 8.4、Flyway，前端使用 HTML、CSS 和 JavaScript。页面与 API 由同一应用提供，无需登录，仅用于本机演示。

功能包括新增待办、查看列表、标记完成、取消完成和删除。所有数据真实写入项目专属 MySQL，刷新页面和重启应用后仍保留。不使用内存 Map 或 localStorage 代替数据库。

## 2. 业务规则

- 创建待办时，标题先按项目约定去除首尾空白，不允许空白标题。
- 标题最多 200 个 Unicode code point；前后端采用同一计数及空白处理规则，并测试 emoji 边界。组合字符可能包含多个 code point，示例不按视觉字形计数。
- 新建默认未完成；PATCH 明确传入希望达到的 completed 状态。
- 列表按创建时间倒序，时间相同时按 ID 倒序。
- 操作不存在的记录返回 404，非法输入返回 400；删除成功返回 204。
- 网络或服务器失败有可见提示，失败提交不丢失输入，不伪报保存成功。

## 3. 数据与配置

平台可用时使用其为本项目提供的五个业务数据库环境变量；代码仅引用变量，不读取或展示真实密码。脚本负责明确加载本地配置。迁移账号执行 DDL，应用账号执行 CRUD。

测试连接独立的临时 MySQL，不能将清表用例指向正常业务库。删除源码、归档对话等操作不包含删库。

## 4. 交付内容

需要可构建的 POM、后端接口和业务实现、前端静态页面、Flyway 迁移、真实 MySQL 集成测试、Windows 启动脚本、空值 `.env.example`、正确的 `.gitignore` 和 README。

README 写清环境要求、配置来源、构建测试命令、启动命令、实际端口、停止方式和数据库保留说明。不得把已生成文件、测试通过与本地启动成功混为一谈。

## 5. 验收

1. 在新的专属空库上迁移成功。
2. 通过 HTTP 完成创建、列表、完成切换和删除，核实真实数据库结果。
3. 通过空白、超长、中文和 emoji 等边界用例。
4. 从浏览器创建记录后刷新，数据仍存在。
5. 保留数据库、重启应用，记录仍存在。
6. 本机默认端口被其他服务占用时，提供明确提示或使用经确认的替代端口，不停止无关服务。

这是需求资料。实际执行范围、计划审批、测试环境和最终文件接受方式由用户当前指令与平台流程决定，文档本身不触发操作。
