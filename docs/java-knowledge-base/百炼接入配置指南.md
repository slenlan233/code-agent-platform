# 百炼知识库接入配置指南

版本：1.0｜核对日期：2026-10-27
适用范围：当前项目的 `code_agent_platform.integrations.bailian` 接入方式。

这份说明供你配置平台使用，不建议上传到 Java 通用知识库。文中的示例没有任何真实凭证，本次也没有创建云资源或更改本地配置。

## 1. 先分清四个值

| 本项目变量名 | 在哪里取得 | 作用 |
| --- | --- | --- |
| `ALIBABA_CLOUD_ACCESS_KEY_ID` | 阿里云 RAM 用户的 AccessKey | 标识调用身份 |
| `ALIBABA_CLOUD_ACCESS_KEY_SECRET` | 与上面同一次创建的 AccessKey Secret | SDK 签名凭证 |
| `BAILIAN_WORKSPACE_ID` | 百炼当前业务空间的 Workspace ID | 指定知识库所在空间 |
| `BAILIAN_INDEX_ID` | 百炼知识库的知识库 ID / index_id | 指定要检索的知识库 |

前两个必须是一对；后两个必须指向相同地域、相同业务空间下的目标知识库。Workspace ID 不是阿里云账号 UID；Index ID 不是应用 APP ID、文件 ID 或上传任务 ID。

当前代码使用阿里云百炼 OpenAPI SDK 的 Retrieve 接口，以 AccessKey 签名；`BAILIAN_API_KEY`、`DASHSCOPE_API_KEY` 或调用模型的 API Key 不能填到这两个 AccessKey 变量里。百炼同时提供其他鉴权路径，不能把它们的配置混用。[Retrieve 接口说明](https://help.aliyun.com/zh/model-studio/api-bailian-2023-12-29-retrieve)

## 2. 获取 AccessKey ID 和 AccessKey Secret

建议为这个本地 Agent 使用独立 RAM 用户的 AccessKey。

1. 以能管理 RAM 用户的身份登录 [RAM 控制台](https://ram.console.aliyun.com/)。
2. 进入「身份管理 → 用户」，没有合适的用户就先创建一个。
3. 打开用户详情，在「凭证管理」页的 AccessKey 区域点击「创建 AccessKey」。
4. 按界面选择实际使用场景并完成验证。
5. 将同一次创建得到的 ID 与 Secret 分别保存到本地对应配置项。

Secret 只在创建时显示一次。若没有保存，不能再次查询原 Secret，需要创建新的密钥对。[官方创建步骤与说明](https://help.aliyun.com/zh/ram/user-guide/create-an-accesskey-pair)

检索身份还需要百炼 API 权限，并加入目标业务空间；Retrieve 所需权限包含 `sfm:Retrieve`。官方列出的系统策略 `AliyunBailianDataFullAccess` 包含该权限，但范围也包含其他数据操作；仅供本 Agent 查询时可由管理员按实际需要收敛授权。控制台上传文档和本地程序检索可以使用不同身份。[百炼 API 前置条件](https://help.aliyun.com/zh/model-studio/rag-knowledge-base-api-guide)

## 3. 获取业务空间 ID

1. 登录 [阿里云百炼控制台](https://bailian.console.aliyun.com/)，选择「华北 2（北京）」及准备放置知识库的业务空间。
2. 从页面右上角的业务空间入口打开空间信息，在弹出的信息中复制 Workspace ID。
3. 如果你有业务空间管理权限，也可在业务空间管理列表的 Workspace ID 列复制。

RAM 用户通常只能看到已加入的业务空间。界面入口以当前控制台为准，官方说明包含对应图示。[获取 Workspace ID](https://help.aliyun.com/zh/model-studio/obtain-the-app-id-and-workspace-id)

当前本地集成的 endpoint 固定为 `bailian.cn-beijing.aliyuncs.com`，所以本指南选择北京地域。若知识库在其他地域，需先调整并验证接入代码，不能只替换空间 ID 就假设可用。

## 4. 创建知识库并获取知识库 ID

1. 在同一业务空间进入「数据接入 → 知识管理」，点击「创建知识库」。
2. 名称可填写「Java开发规范」；类型选择「文档搜索」，场景可选「基础文档问答」。
3. 上传本包「上传到知识库」目录中的七份 `.md`，解析和切片先使用默认配置。
4. 等待文件处理完成、知识库变为「已就绪」。[创建与上传说明](https://help.aliyun.com/zh/model-studio/rag-knowledge-base)
5. 在知识管理页面点击目标知识库，复制其知识库 ID，填入 `BAILIAN_INDEX_ID`。[知识库 ID 获取位置](https://help.aliyun.com/zh/model-studio/rag/quickstart)

压缩包用于便于拷贝，上传前先解压，选择 Markdown 文件。Todo 需求示例按需加入，避免污染其他业务项目的检索。

## 5. 在本地填写

编辑编程平台根目录的 `.env`，本机路径是：

```text
D:\学习Java\ai项目\3.xiangmu\.env
```

这是 Agent 平台的配置，不是 Todo 项目目录的数据库 `.env`。已有其他配置保留，四项各占一行，替换占位说明：

```dotenv
ALIBABA_CLOUD_ACCESS_KEY_ID=替换为RAM用户的AccessKey_ID
ALIBABA_CLOUD_ACCESS_KEY_SECRET=替换为同一对AccessKey_Secret
BAILIAN_WORKSPACE_ID=替换为北京业务空间ID
BAILIAN_INDEX_ID=替换为该空间中的知识库ID
```

这四行是文件内容，不是可以直接粘贴进 PowerShell 执行的命令。不要将真实 `.env` 上传到知识库或提交到 Git，也不需要把 Secret 发到对话里。

## 6. 填完还要启用与验证

当前平台将连接配置与项目授权分开：

- 在 `agent-config.local.json` 原有 `mcp_servers` 中，将 `bailian.enabled` 改为 `true`，保留其他配置。
- 需要使用知识库的项目，其 `mcp_servers` 列表包含 `bailian`，同时保留原有已选服务。该项目字段可以通过现有 `project-config` CLI 更新。
- 停止并重新启动工作台，让新配置进入服务进程。若仍运行旧进程，单纯重新打开网页不会加载新凭证；启动脚本复用现有服务时也不会替你重启。

这些是之后接入时要做的操作，本次没有自动启用。管理员或进程环境中已存在的同名变量优先于当前 `.env` 加载，修改后不生效时应核对来源，不输出秘密值。

验收分两步：先检查 MCP 连接及 `mcp__bailian__query_rag` 工具是否可用，再实际询问“Flyway 已执行的迁移能直接修改吗？”等问题，确认返回相关文档与片段。只有 MCP 连接成功，不能证明云端身份、知识库 ID 和检索都正确。

## 7. 常见错误

| 现象 | 检查方向 |
| --- | --- |
| 提示缺少环境变量 | 是否填在平台根目录 `.env`，是否已重启对应服务 |
| 无权限或 403 | AccessKey 对应身份是否有 API 权限、是否加入目标空间 |
| 找不到知识库 | Workspace ID、Index ID、地域是否对应，是否误填 APP ID |
| 返回空结果 | 文档是否已就绪，问题是否相关，是否上传到当前目标库 |
| 工具未显示 | 全局开关与当前项目的服务选择是否都包含百炼 |
| 有工具但查询失败 | 检查云端实际请求错误，不能只重试工具发现 |

接入这个知识库不要求更换当前 DeepSeek 模型：百炼负责检索文档，模型负责结合检索内容完成回答和开发任务。
