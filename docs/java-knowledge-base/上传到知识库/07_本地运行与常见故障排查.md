# 本地运行与常见故障排查

文档编号：JAVA-KB-07｜版本：1.0｜日期：2026-10-27
适用范围：Windows、PowerShell 7、Java 17、Maven、Spring Boot 3.5.x 和本机 MySQL。性质：运行与排查建议，命令中的项目路径需替换为实际值。

## 1. 启动前检查

在新项目根目录打开终端，检查：

```powershell
java -version
mvn -version
```

Maven 输出中的 Java 路径和版本也应正确，仅 `java -version` 正确不能保证 Maven 用了相同 JDK。检查 `pom.xml`、迁移文件、前端静态资源以及本地连接配置是否存在。

README 应说明是否依赖额外组件、具体启动命令、默认端口与如何停止。不要在启动说明中要求用户先猜数据库账号或复制聊天中的密码。

## 2. 启动与端口

如果项目已经提供经过核对的启动脚本，可在根目录执行：

```powershell
.\scripts\start.ps1
```

脚本应加载该项目允许的配置，检查必要项，启动服务并返回真实退出码。不能输出密码，也不能为了单个项目修改系统级执行策略。若确需调整当前进程运行方式，应说明原因并保持范围最小。

在环境变量已经正确提供的情况下，也可以直接执行项目支持的命令，例如：

```powershell
mvn spring-boot:run
```

不要把这个命令当成自动加载 `.env` 的替代方法。最终访问地址以启动成功日志中的实际端口为准；本套资料的可选默认端口是 8081，但既有项目不必强制改成它。

## 3. 打开 8080 出现 Tomcat 首页

说明当前 URL 对应的服务返回了 Tomcat 默认页面，不能据此认定新项目启动成功。先检查新应用控制台是否启动成功，再查看端口占用：

```powershell
Get-NetTCPConnection -LocalPort 8080 -State Listen |
    Select-Object LocalAddress, LocalPort, OwningProcess
```

用返回的 PID 查询进程并核实身份。不要看到 java 进程就全部结束，也不要自动停止其他项目的 Tomcat。可以选择经检查未占用的端口，通过项目支持的 `APP_SERVER_PORT` 或 Spring Boot 参数设置，并更新实际打开的 URL。

如果页面正常但 `/api/...` 不通，还要核对应用上下文路径、相对 API 路径和静态资源是否确实属于当前项目。

## 4. 数据库连接失败

| 现象 | 优先检查 |
| --- | --- |
| Connection refused | MySQL 服务、主机和端口是否正确 |
| Access denied | 当前环境账号、密码和 MySQL 授权来源 |
| Unknown database | 专属库是否已由管理入口创建，URL 是否正确 |
| 无法解析配置占位符 | 环境变量是否加载到实际启动进程 |
| Flyway 权限错误 | 是否误用业务只读或 CRUD 账号执行 DDL |
| checksum mismatch | 已执行迁移是否被修改，源码与库版本是否对应 |

只展示脱敏连接信息排错。不要把密码贴进命令日志、README 或 Agent 消息。修复账号或库配置不等于可以删除原有库；数据操作遵循明确授权。

## 5. 构建或依赖失败

首次构建需要下载依赖时，离线模式可能失败；网络、代理、镜像站和依赖版本错误要分别排查。不要为让测试通过直接删除测试、切换内存数据库或跳过迁移。

说明使用的是 Maven wrapper 还是系统 Maven，依赖缓存是否完整。报错里涉及 TLS、DNS 或仓库连接时，保留必要错误并报告环境限制，不把它误归为业务代码逻辑问题。

## 6. Docker 与网络

Docker Desktop 没有运行时，容器测试无法开始。`docker info` 可检查引擎是否可用，`docker ps -a` 可查看存在的容器；临时测试容器采用自动清理策略时，测试结束后列表中可能看不到它。

Agent 工作台、项目源码、数据库与测试容器可以分别运行在不同位置；不能因为“用 Docker 测试”就说 Agent 或整个项目一直住在 Docker 里。

容器访问宿主机地址与普通本机进程不同。网络隔离是执行器策略，不能假定有外网；拉依赖、连接数据库所需网络应由配置明确提供。若网络不可用，应显示具体阻塞原因。

## 7. Windows Java 临时目录问题

只有当日志明确涉及临时目录或本地 socket 路径时，才评估设置项目专属 Java 临时目录。使用存在、可写且路径较短的绝对目录，在当前项目启动进程上传递经过核对的参数；不要不加分析地修改整个系统的 TEMP/TMP。

路径带中文、空格或特殊字符时，启动脚本必须正确引用。不同 JDK 发行版或补丁版本的问题要结合实际异常与版本复现，不能把一次演示中的参数当作所有项目必需配置。

## 8. 最后核实

看到服务启动成功日志后，用实际 URL 检查页面和 API，再执行一次新增、刷新、状态切换及重启保留。给用户的运行答复应优先提供可复制命令、真实地址、停止方式和当前是否已经启动，避免用代码审查摘要代替操作说明。
